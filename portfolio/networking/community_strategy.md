## 2. Normas de Participación por Plataforma

### 🔴 Reddit (r/sportsanalytics & r/NBAanalytics)
- **Qué publicar**: Casos de estudio técnicos con código en bloque o gráficos limpios (PNG alta resolución). Explicar el problema antes de poner el enlace.
- **Qué NO publicar**: Títulos tipo clickbait (*"¡He creado la mejor herramienta de baloncesto!"*), enlaces directos sin contexto o peticiones directas de trabajo.
- **Etiqueta recomendada**: `[OC]` (Original Content) o `Project / Analysis`.

### 🐍 PySport & Open Source Sports (GitHub / Discord)
- **Qué publicar**: Enviar una pull request para añadir el repositorio a la sección de proyectos de baloncesto de *Awesome Sports Analytics* de PySport.
- **Enfoque técnico**: Destacar el uso de DuckDB, PyArrow, Parquet y la integración con R/Quarto.

### 🐦 Twitter / X Sports Data Community
- **Qué publicar**: Hilos breves de 3–4 tweets con 1 gráfico llamativo en el primer tweet, explicando un concepto táctico (por ejemplo, cómo defender a un tirador tras bloqueo directo).
- **Hashtags clave**: `#BasketballAnalytics`, `#SportsData`, `#RStats`, `#Python`.
