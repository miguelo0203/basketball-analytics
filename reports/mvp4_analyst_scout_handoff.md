## 1. Operational Boundary

The analytics department does **NOT** issue autonomous "Sign / Do Not Sign" directives. Quantitative metrics indicate **WHAT** a candidate produced in international tournament environments; video scouting and contextual interviews must verify **HOW** and **WHY**.

```
+----------------------------------------------------------------------------------------------------+
|                                      EVIDENCE BOUNDARY MATRIX                                      |
+----------------------------------------------------------------------------------------------------+
| **DATA EVIDENCE (CONFIRMED)**        | - 3-point attempt rate (3PAr) and true shooting efficiency (TS%)   |
|                                      | - Secondary creation frequency (AST% and estimated AST/TOV)        |
|                                      | - Defensive event creation (STL/40 and BLK/40)                     |
|                                      | - Tournament minutes and sample reliability tier                   |
+----------------------------------------------------------------------------------------------------+
| **VIDEO EVIDENCE (REQUIRES SCOUT)**  | - Pick-and-roll passing accuracy against aggressive blitz/hedges   |
|                                      | - Contested catch-and-shoot release mechanics under hard closeouts |
|                                      | - Point-of-attack screen navigation and recovery footwork          |
|                                      | - Transition rim decisions against loaded back-line defenses       |
+----------------------------------------------------------------------------------------------------+
| **UNKNOWN (REQUIRES INTERVIEWS/MED)**| - Medical durability, injury history, and structural joint health  |
|                                      | - Locker room leadership, coachability, and tactical receptivity   |
|                                      | - Salary expectations and domestic contract buyout status          |
+----------------------------------------------------------------------------------------------------+
```

## 2. Specific Video Sampling Hypotheses by Shortlisted Case

### Case A: Secondary Creation Wing (Target: Bogdan Bogdanović / Rudy Fernández / Luka Dončić)
1. **[HIPÓTESIS PARA VÍDEO 1 - Closeout Attack & Pull-Up Release]**:
   - *Clip Criteria*: Sample 10 half-court possessions where defenders close out hard to the 3-point line.
   - *Scouting Check*: Does the player attack the high foot of the closeout and pull up in the mid-range ($15\text{ ft}$), or kick out to the weak-side corner?
2. **[HIPÓTESIS PARA VÍDEO 2 - P&R Low-Man Read]**:
   - *Clip Criteria*: 4th quarter side pick-and-roll possessions against Drop coverage.
   - *Scouting Check*: Does the player manipulate the tag defender with eye deception before delivering the corner skip pass?

---

### Case B: Defensive / Spacing Guard (Target: Marco Belinelli / Andreas Obst / Klemen Prepelič)
1. **[HIPÓTESIS PARA VÍDEO 1 - Off-Ball Screen Footwork]**:
   - *Clip Criteria*: Staggered screen and flare screen actions.
   - *Scouting Check*: Assess footwork balance (1-2 step vs hop) when catching on the move from right-to-left drift.
2. **[HIPÓTESIS PARA VÍDEO 2 - Point-of-Attack Screen Containment]**:
   - *Clip Criteria*: Defensive possessions against elite downhill point guards.
   - *Scouting Check*: Does the guard get cleanly eliminated by middle ball screens, or does he fight over the top to contest from behind?

---

### Case C: Stretch / Connector Forward (Target: Dirk Nowitzki / Danilo Gallinari / Juancho Hernangómez)
1. **[HIPÓTESIS PARA VÍDEO 1 - Pick-and-Pop Spacing Depth]**:
   - *Clip Criteria*: Top-of-the-key pick-and-pop actions.
   - *Scouting Check*: Does the forward pop cleanly to $24\text{ ft}$ to create genuine rim-protection conflict, or hover in the non-threatening mid-range ($20\text{ ft}$)?
2. **[HIPÓTESIS PARA VÍDEO 2 - Defensive Glass Boxing Out]**:
   - *Clip Criteria*: Defensive rebounding situations after weak-side help rotations.
   - *Scouting Check*: Does the player seek out contact to box out athletic wings, or rely on uncontested rebounds?
