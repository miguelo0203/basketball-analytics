## 2. TOP 5 ABSOLUTO: Las 5 Comunidades Clave para Miguel

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ 🥇 1. PySport Community (Global / Open Source Sports Analytics)                         │
│    Por qué: Es el epicentro del código abierto en deportes. Reúne a data scientists    │
│    de clubes y empresas tecnológicas de datos. El proyecto encaja al 100% como caso   │
│    de estudio de DuckDB + Python.                                                      │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 🥈 2. SportsDataverse (hoopR / wehoop)                                                 │
│    Por qué: Es la iniciativa de datos de baloncesto más respetada en la comunidad      │
│    analítica. Permite aprender estándares de datos abiertos y conectar con analistas. │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 🥉 3. Reddit r/sportsanalytics                                                         │
│    Por qué: Comunidad activa a diario con debate metodológico honesto. Excelente       │
│    para recibir feedback sobre la validación walk-forward sin sesgo comercial.         │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 🏅 4. PyData Madrid (Comunidad Presencial & Online en Madrid)                          │
│    Por qué: Conexión local directa en Madrid con ingenieros de datos y científicos de │
│    datos senior. Ideal para networking técnico sin intermediarios.                     │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 🎖️ 5. Asociación Española de Entrenadores de Baloncesto (AEEB)                        │
│    Por qué: Enseña a hablar el idioma del entrenador de pista. Imprescindible para no  │
│    caer en el error del analista teórico que desconoce la realidad del banquillo.     │
└────────────────────────────────────────────────────────────────────────────────────────┘
```
