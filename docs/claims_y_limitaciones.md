# Gobernanza de Claims Públicos y Matriz de Verificación
## International Basketball Analytics (2005–2024)

### 1. Principio Fundamental de Comunicación

> *"El sistema organiza evidencia empírica, detecta contradicciones tácticas y cuantifica la incertidumbre para apoyar la toma de decisiones del cuerpo técnico. En ningún caso sustituye el juicio ni la autoridad del entrenador."*

---

### 2. Clasificación de Claims en Tres Niveles

```
+----------------------------------------------------------------------------------------------------+
| NIVEL       | EJEMPLOS DE AFIRMACIONES PERMITIDAS / CONDICIONADAS / PROHIBIDAS                     |
+----------------------------------------------------------------------------------------------------+
| **VERDE**   | • "Construí un pipeline analítico reproducible de 9 capas."                         |
| (Seguro)    | • "Implementé validación temporal walk-forward en 17 folds sin fuga de datos."       |
|             | • "Evalué modelos LightGBM out-of-sample sobre 1.105 partidos."                      |
|             | • "Integré evidencia estadística (Four Factors) y cinta de vídeo (κ = 0.80)."        |
|             | • "Construí 180.000 simulaciones Monte Carlo con shrinkage de probabilidades."       |
|             | • "Diseñé una capa de decision support con briefs prepartido de 1.5 páginas."        |
|             | • "Automaticé un framework de QA con 201 tests y 100% de tasa de éxito."            |
+----------------------------------------------------------------------------------------------------+
| **AMARILLO**| • "El modelo supervisado obtuvo ROC-AUC = 0.7613 y Brier Score = 0.1967."            |
| (Requiere   |   ➔ Condición: Aclarar protocolo temporal walk-forward en dataset histórico FIBA.   |
| Contexto)   | • "El sistema alcanzó un 72.2% de Top-1 hit rate en 18 torneos Monte Carlo."         |
|             |   ➔ Condición: Describir como consistencia retrospectiva, no garantía de futuro.     |
|             | • "La calibración probabilística obtuvo un ECE de 0.0314 (3.14%)."                   |
|             |   ➔ Condición: Presentar como calibración empírica en bins de probabilidad.          |

|             |   ➔ Condición: Presentar como taxonomía estadística descriptiva, no etiqueta fija.  |

| **ROJO**    | ❌ "Predice el futuro o adivina quién va a ganar con certeza absoluta."              |
| (Totalmente | ❌ "Demuestra causalidad estricta o garantiza que un cambio táctico produce victoria."|

|             | ❌ "Es una herramienta de scouting comercial de fichajes o mercado de agentes."     |
|             | ❌ "Funciona automáticamente en cualquier liga sin calibración local."               |
```
