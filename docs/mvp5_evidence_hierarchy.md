# Formal Basketball Evidence Hierarchy
## Methodological Framework for Integrated Analytics & Scouting

---

## 1. The 5-Level Evidence Hierarchy

To maintain scientific integrity and prevent cognitive bias, all analytical assertions in this project are governed by an explicit **Evidence Hierarchy**:

```
+----------------------------------------------------------------------------------------------------+
| LEVEL | EVIDENCE TIER                 | DEFINITION & EMPIRICAL SOURCE     | OPERATIONAL WEIGHT     |
+----------------------------------------------------------------------------------------------------+
| **1** | **Direct Video Evidence**     | Specific possession / action      | **PRIMARY TRUTH**      |
|       |                               | observed on film with documented  | Overrides unadjusted   |
|       |                               | tactical execution.               | boxscore metrics.      |
+----------------------------------------------------------------------------------------------------+
| **2** | **Repeated Video Pattern**    | Consistent behavioral pattern     | **HIGH CONFIDENCE**    |
|       |                               | observed across multiple games /  | Establishes player's   |
|       |                               | tactical contexts.                | baseline habits.       |
+----------------------------------------------------------------------------------------------------+
| **3** | **Quantitative Proxy**        | Pace-adjusted rate metrics and    | **HYPOTHESIS SOURCE**  |
|       |                               | efficiency indicators (TS%, 3PAr, | Surfaces candidates;   |
|       |                               | AST%, STL/40, Four Factors).      | requires tape check.   |
+----------------------------------------------------------------------------------------------------+
| **4** | **Role / Context Inference**  | Tactical scheme, federation tier, | **SECONDARY CONTEXT**  |
|       |                               | and teammate synergy effects.     | Explains role limits.  |
+----------------------------------------------------------------------------------------------------+
| **5** | **Reputation / Narrative**    | Media hype, career accolades,     | **EXCLUDED FROM PROOF**|
|       |                               | awards, past contracts.           | Strictly forbidden as  |
|       |                               |                                   | analytical evidence.   |
+----------------------------------------------------------------------------------------------------+
```

---

## 2. Decision Rules

1. **Statistical signals are hypotheses, not conclusions**.
2. **Video observations calibrate the quantitative model**.
3. **Reputation must never override observed empirical evidence**.
